## HTML - HyperText Markup language
O HTML é uma marcação de testo, ou seja , seu propósito é estruturar textualmente uma página da web/documentos.

## Elementos ou tags
Para estruturar um documento HTML ultilizamos tags/elementos, por exemplo, para indicar que um texto é um parágrafo ultilizamos a tag <p>texto do parágrafo </p>.
Existem tags que tem abertura <p> e fechamentos </p>, mas também existem tags "autofechantes"que não possuem fechamento, como a tag <img> de imagem.

### Exemplos de tags:
- p : Parágrafo 
- h1 : Titulo principal
- h2 : Titulo secundário
