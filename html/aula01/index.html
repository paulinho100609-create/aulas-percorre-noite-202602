HTML - HyperText Markup Language

O HTML é uma marcação de testo, ou seja , seu propósito é estruturar textualmente uma página da web/documentos.

Elementos ou tags

Para estruturar um documento HTML ultilizamos tags/elementos, por exemplo, para indicar que um texto é um parágrafo ultilizamos a tag < p >texto do parágrafo . Existem tags que tem abertura < p > e fechamentos

, mas também existem tags

Exemplos de tags:

  • p : parágrafo
  • h1 : Titulo principal
  • h2 : Titulo secundário
